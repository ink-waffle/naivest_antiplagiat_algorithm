## Простейший алгоритм для обнаружения плагиата файлов, теперь на Brainfuck

Вся логика живёт в `compare.bf`: чтение строк, препроцессинг, расстояние Левенштейна, мера схожести и округление до сотых как у `round`. `compare.py` остался только интерпретатором Brainfuck и прослойкой, которая читает файлы с диска.

<b>1 аргумент - текстовый файл с путями файлов для сравнения

2 аргумент - директория выходного файла с результатами сравнения пар</b>

```sh
python compare.py input.txt output.txt
```

Подойдёт и любой 8-битный интерпретатор Brainfuck, где EOF даёт 0: на вход первый файл, байт `0xFF`, второй файл, байт `0xFF`, и так для каждой пары.

```sh
(cat a.py; printf '\377'; cat b.py; printf '\377') | bf compare.bf
```
